## 0. 한 줄 요약

- **튀르키예**: "한국 소개" 대형 전문 계정은 검색으로 거의 안 잡힘 → **빈 자리(기회)**. 대신 언론이 반복해서 쓰는 단골 이야기는 확실함: ① 6·25 참전·"형제의 나라"(Kore gazisi), ② 2002 월드컵 터키 국기 응원, ③ 김민재 페네르바흐체 + 지진 기부, ④ 한국인이 터키를 좋아한다는 이야기. 단, 2022 "허위정보법"(TCK 217/A) 때문에 **튀르키예 국내 정치는 절대 건드리지 말 것**.
- **스페인어권**: 시장은 크고 이미 증명됨. 멕시코 한류 팬 약 2,780만 명(국제교류재단, 2023년 말 기준). 한국 크리에이터 **Chingu Amiga(김수진)** 가 KOFICE 2025 조사에서 "중남미에서 BTS 다음으로 영향력 있는 한류 인물" 2위. 하지만 같은 사람이 2025년 "가난한 가족 이용", "문화 전유", "세금" 논란으로 집중 공격 → **"남의 나라를 소재로 돈 번다"는 인상이 가장 큰 위험**.

## 3. 언어·번역 함정

### 3-1. 스페인어: 어느 나라 말로 쓸까

- **BBC Mundo 방식**: 공식 "중립 스페인어" 규칙은 없고, **가장 널리 알려진 단어(대개 멕시코식)** 를 고름. 스페인식(castellano)이 아닌 "중남미식 스페인어"를 의도적으로 사용. 기준은 RAE보다 **Fundéu**를 더 참고. 독자 호칭은 예전 usted → 지금 **tú**. ([Language Acts](https://languageacts.org/blog/bbc-mundo-reporting-latin-american-world-london/))
- CNN en Español, DW Español, Univision도 "중립" 쪽으로 이동 중 ([Dialnet 논문](https://dialnet.unirioja.es/descarga/articulo/9322691.pdf))
- 중립 스페인어는 "어디서도 쓰진 않지만 어디서나 이해되는 말", 비속어를 부드럽게 함 ([SpanishDict](https://www.spanishdict.com/guide/what-is-espanol-neutro))
- Pictoline·El País América 스타일 가이드는 확인 못 함 **[미검증]**

**→ @hoyencorea 규칙 제안**: 멕시코 친화적 중립 스페인어 + **tú** (vos 금지, vosotros 금지 → "ustedes") + 비속어 금지.

| 피해야 할 단어 | 문제 | 대신 |
|---|---|---|
| coger (잡다) | 중남미(멕시코·아르헨) 성적 의미 | tomar, agarrar |
| vosotros / habéis | 스페인에서만 | ustedes / han |
| vos / tenés / querés | 아르헨·우루과이 voseo | tú / tienes / quieres |
| guagua | 카리브=버스, 칠레=아기 | autobús |
| ordenador / móvil / zumo / coche | 스페인식 | computadora / celular / jugo / auto(carro) |
| concha, pico, pija, bicho | 나라별로 성적 의미 | 사용 금지 |
| chamba, chido, güey / guay, tío | 각각 멕시코 / 스페인 속어 | trabajo, genial, chico |
| 금액 | 원(KRW)만 쓰면 감 안 옴 | "USD + MXN" 병기, 가끔 EUR·COP·ARS |
| 날짜 | 1/11 혼동 | "1 de noviembre" 글자로 |

(위 단어 표는 일반 언어 지식 기반, 개별 출처 없음)

### 3-2. 튀르키예어: siz vs sen

- 튀르키예 브랜드는 Instagram에서 보통 **친근한 "sen"**, LinkedIn 등에서는 **"siz"** 를 쓰는 경향 ([Ticimax](https://www.ticimax.com/blog/sosyal-medya-plani-hazirlama)). 친근하고 싶으면 sen, 기관다운 신뢰를 원하면 siz ([Para Dergi](https://paradergi.com.tr/life-style/2022/03/28/firmalar-icin-sosyal-medyada-lincten-korunma-rehberi)). 같은 글은 "비판 댓글과 싸우지 말 것"도 강조.
- 뉴스 계정 전용 규칙은 못 찾음 **[미검증]**.

**→ @koredebugun 규칙 제안**:
- **본문(뉴스 사실)**: 주어 없는 중립 문체 (예: "Güney Kore'de doğum oranı 0,72'ye düştü.")
- **독자에게 묻는 부분/CTA**: "sen"을 피하고 **"siz" 또는 "-elim" 형** (예: "Sizce Türkiye'de de olur mu?", "Birlikte bakalım") — 30~50대 남성·보수층 거부감 최소화 [추정]

## 5. 이 프로젝트에 주는 교훈 10가지

1. **빈 자리가 있다.** 튀르키예어·스페인어 모두 "한국 사회 뉴스를 매일 정리하는 계정"은 확인된 대형 경쟁자가 없다. 경쟁 상대는 "얼굴 나오는 브이로거"이지 뉴스 계정이 아니다 → **신뢰·정확성·꾸준함**으로 차별화.

5. **가난·피해자·소수자를 소재로 "돈 버는" 인상은 치명적.** Chingu Amiga 캔슬 사례. 인물 사진은 동의된 것만, 비극 뉴스엔 광고·협찬 붙이지 말 것.
6. **스폰서·정부 지원은 투명하게.** 튀르키예 "영향력 대리인" 법안 재추진 가능성 + 스페인어권 반감. 협찬은 무조건 표기.
